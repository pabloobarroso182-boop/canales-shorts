# Canales de YouTube Shorts (copia privada)

- **Reglas de todo:** [`INSTRUCCIONES_SHORTS.md`](INSTRUCCIONES_SHORTS.md).
- **Para seguir en una conversación nueva:** «Recupera mis proyectos de Shorts del repositorio canales-shorts y sigue al pie de la letra INSTRUCCIONES_SHORTS.md (sección 8). Vuelve a crear la tarea diaria de las 18:00 y dime qué falta.»
- **Carpetas:**
  - `curiosidades-canal/`: Datos Curiosos;
  - `canal2-shorts/`: Ahora Lo Entiendes;
  - `canales-nuevos/`: marca, voces y reglas de los canales nuevos;
  - `estudio-mercado-shorts/`: estudios;
  - `tools/`: utilidades.
- **No se guardan aquí:** claves, vídeos MP4 y audios WAV (pesados) ni dependencias reinstalables.
